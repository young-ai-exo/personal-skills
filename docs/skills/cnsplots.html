cnsplots

Publication-ready scientific figures in Python with Cell, Nature, and Science styling.

v3.0.5 derivative-enhancement BSD-3-Clause verified · cnsplots 0.8.0

Creates, revises, and debugs publication-ready scientific figures in Python using cnsplots, matplotlib, seaborn, or scanpy. Enforces a closed-loop 6-step workflow, a ~100 pt panel sizing contract, Cell-palette and Arial-first typography, and editable PDF/SVG output. Supports native cnsplots (Mode A) and a bundled pure matplotlib/seaborn style sheet (Mode B).

What the skill enforces

6-step closed loop

Bootstrap environment and style → profile data and select the plot type → choose layout and canvas budget → build at ~100 pt proportions → extract statistical truth → render a preview and inspect it visually.

100 pt panel contract

Panels are calibrated around 80–150 pt, with 100 pt as the baseline. Dimensions are physical points, not screen pixels; 100 pt is 500 px at 360 dpi.

House style

Cell 10-color qualitative palette, viridis continuous palette, Arial-first font stack, 8/7 pt type hierarchy, 0.5 pt spines, opaque white background, and 360 dpi display/export.

Dual execution modes

Mode A uses the cnsplots package. Mode B copies the generated cns_cell.mplstyle into the project and uses pure matplotlib/seaborn with no cnsplots dependency.

Guardrails

No manual font or marker blow-ups, fixed category order via hue_order or order, explicit statistical test reporting, and no fabricated plot structures.

PDF-first delivery

PDF is the primary artifact; SVG is for Illustrator editing; a 360 dpi PNG is only a visual preview. The model inspects the rendered preview instead of checking only that a file exists.
