cnsplots

Publication-quality scientific figures in Python with Cell, Nature, and Science styling.

v1.8.0 derivative-enhancement BSD-3-Clause verified · cnsplots 0.8.0

Generates, revises, and debugs publication-quality scientific figures in Python using the cnsplots package. Triggers on requests for journal-style plots, multi-panel or grid figures, survival/volcano/GSEA/ROC/heatmap plots, or Illustrator-editable vector output. Also covers applying the cnsplots style to plain matplotlib, seaborn, or scanpy axes.

Upstream ships its own skill. Running cnsplots skill install installs the official version. This one adds executable verification on top. Prefer upstream if you want to track it exactly.

What it adds over upstream

check_env.py

Reports interpreter, package version, backend, and whether mutool is installed before any plotting.

inspect_api.py

Prints the installed signature and docstring so the agent stops guessing at API shapes that shift between releases.

validate_output.py

Checks the artifact exists, is non-empty, has correct magic bytes, and counts SVG text elements to catch text flattened into paths.

dump_style.py

Measures the rcParams diff, every settings value, the accepted palette names, and the color constants from the installed package, so no documented number is transcribed by hand.

troubleshooting.md

25 documented failure modes with fixes, each reproduced against the installed version.

rcparams.md + settings-catalog.md

The full style contract: which rcParams the package sets, and the rule for custom artists - inherit the value, or read it from config, never restate it.

composition-patterns.md

When to use a matplotlib grid, multipanel, or a GridSpec inside a host panel, with the measurements behind each rule.

dense-figures.md

Full journal figures: negative offsets that reclaim reserved space, embedded raster images, composite plotter internal axes, and reworking generated annotations. Derived from reproducing the upstream showcase.

recommended_overrides.py

Measured reasoning for overriding palette_seq to viridis (gnuplot is non-monotonic in CIE L* with CV 0.66 and 39 greyscale collisions) and moving Arial ahead of Helvetica (Cell requires Arial; macOS defaults embed Helvetica). Emits a ready three-line block with --code.

journal-specs.md + journal_preset.py

Cell, Nature and Science column widths converted to cnsplots points, plus type, line-weight, resolution, format and colour-accessibility limits, each with its source URL. The script checks the installed defaults against a chosen journal and can emit a ready settings block.

color-strategy.md

One palette per figure, keeping a variable on one color across panels, qualitative vs sequential vs diverging, and colour-vision plus greyscale legibility checks. Audits the showcase's eight-palette variety and explains why that is the wrong model to copy.

templates/

Four runnable layout templates - uniform grid, labeled heterogeneous figure, an aligned grid embedded in a labeled figure, and a dense showcase-style figure. The upstream showcase source is vendored alongside them, verbatim, as reference material.

Workflow the skill enforces

  • Probe the environment before writing code.
  • Inspect the data, then confirm each function signature against the installed version.
  • Build with matplotlib.use("Agg") for headless runs.
  • Save, then validate the artifact - never claim success on unrun code.
  • Report the script, output path, and every scientific assumption made.

Traps it guards against

Points, not inches

cns.figure(180, 150) is 180×150 points (1/72 inch), rendered at 144 dpi, so the raster is 360×300. Writing cns.figure(6, 4) out of matplotlib habit yields a 6×4 point canvas. Pass unit="in" or unit="mm" for a physical size. Separately, the default savefig_bbox='tight' crops the saved file to its artists, so a journal column width set on the canvas is not necessarily the width on disk; bbox_inches=None preserves the full canvas.

Return types are not uniform

heatmapplot and dotplot return backend-native plotter objects, vennplot returns a matplotlib-venn object, and upsetplot returns panel axes. None are a plain Axes, so a bare .set(...) raises AttributeError. In 0.8.0 figure returns the styled Figure rather than None, while setup_matplotlib, setup_ax, and take_legend_out still return None.

multipanel does not align panel edges

Each panel's outer width includes a reserve measured from its rendered y-axis decorations, so panels whose tick labels differ in width get different axes left edges. Three below=-stacked panels at y magnitudes 1, 1e5, and 10 landed at x0 = 0.065 / 0.114 / 0.075. Neither pad_left nor ax.set_position() fixes it; the latter is reverted on save by multipanel's own draw handler. For an aligned block, one host panel is subdivided with GridSpec instead.

Silent statistical annotations

kdeplot with a two-level hue runs a two-sample Kolmogorov-Smirnov test and prints P = ... on the axes. add_mode=False does not suppress it, and three or more levels produce nothing at all. The skill requires inspecting ax.texts and either naming that test in the caption or removing the annotation deliberately.

Two overrides are recommended before plotting

The installed palette_seq='gnuplot' is non-monotonic in perceptual lightness (CIE L*) with step-size CV 0.66 (identical to the rainbow counterexample jet at 0.65) and produces 39 value pairs >0.1 apart in data space that collapse to within 1 L* in greyscale, making quantitative heatmaps misleading. viridis is strictly monotonic (CV 0.07, zero collisions). The installed font_sans_serif prioritises Helvetica, so Cell Press submissions from macOS embed Helvetica rather than the required Arial. Override both at script top; see recommended_overrides.py --code.

Two defaults are not journal-compliant

Read against the publishers' own author pages: savefig_dpi defaults to 288, below the 300 dpi floor Cell, Nature and Science all require, and title_fontsize defaults to 8 pt, above Nature's 7 pt cap for in-figure text. Line weight at 0.5 pt satisfies all three. The bundled script reports these against the installed version rather than a transcribed table. Also note the journal-named palettes are journal-styled, not compliant: the Science palette places red and green adjacent, which Science's own guidance forbids.

tight_layout is not multipanel's counterpart

multipanel self-corrects through a draw_event handler it connects automatically, because a panel's y-axis decoration width is only knowable after rendering. It keeps axes at exactly the requested pixel size and adjusts the figure around them; tight_layout does the opposite, resizing axes inside a fixed figure. On a multipanel figure tight_layout() is a measured no-op that only emits a warning, since panel axes carry no SubplotSpec. Reserve it for the plt.subplots path.

The showcase is a palette catalog, not a color scheme

Audited every colour decision in the vendored source: Figure 1 uses eight palettes across 18 panels, and four panels plotting iris species render setosa in four different colours. A real figure uses one palette and keeps a category on one colour, via a shared hue_order. The skill also ships a greyscale luma check, which finds real collisions in the default Ecotyper1: entries 4 and 6 differ by 0.005 luma.

Density comes from interlocking, not small margins

A packed figure stacks short panels into the vertical band a tall neighbour occupies, via below=. Both upstream showcase figures use three such stacks. Measured as the fraction of interior all-empty pixel rows, upstream Figure 1 is 4.77% and Figure 2 is 5.44%; the bundled dense template sits at 4.22%, down from 7.96% before the stacks were added. That metric is documented as a reusable acceptance check.

Row membership is not readable from either edge

Panels of differing heights share a row while agreeing on neither y0 nor y1, so both give false wraps. Grouping by vertical overlap reproduces multipanel's internal row grouping using public API only; the dense template ships that check and prints the band structure on save.

A zero exit code is not a passing figure

Every layout defect found while building these versions - a silently wrapped multipanel row, tick labels crashing into the panel below, an unrequested p-value, overlapping heatmap legends in the reproduced showcase - exited zero and wrote a valid file. The skill requires rendering a PNG and looking at it, with savefig_transparent turned off so the preview is not mistaken for a blank image.

Verified example

import matplotlib
matplotlib.use("Agg")

import cnsplots as cns

df = cns.datasets.load_dataset("tips")

mp = cns.multipanel(max_width=540)
ax_a = mp.panel("A", width=150, height=150)
cns.boxplot(data=df, x="day", y="total_bill", ax=ax_a)
ax_b = mp.panel("B", width=150, height=150)
cns.scatterplot(data=df, x="total_bill", y="tip", ax=ax_b)
cns.savefig("multipanel.svg")

Verification record

Tested 2026-10-26 on Python 3.12.14 with cnsplots 0.8.0 and matplotlib 3.10.9. All six scripts including dump_style.py greyscale (now CIE L*), dump_style.py colormap, journal_preset.py and recommended_overrides.py run with correct exit codes, all four templates plus the two vendored upstream showcase scripts execute and were rendered to PNG and visually inspected, and every published rcParams and settings value is measured from the installed package rather than transcribed. Panel alignment, below= stacking, GridSpec durability across savefig, and the inset_axes alternative were each tested empirically. The upstream showcase Figure 1 and Figure 2 were reproduced end to end and inspected, then each showcase-only technique was verified independently rather than copied - including whether the example's private _capture_detached_axes_layout call is load-bearing, which it is not. Cell, Nature and Science figure requirements were read from the publishers' own author pages, converted to points, and a full Nature-compliant preset was run end to end. The documented mutool-missing fallback was confirmed to warn rather than fail.
