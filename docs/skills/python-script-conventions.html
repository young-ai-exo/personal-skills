python-script-conventions

Coding standards for Python 3.12 scripts: layout, imports, type hints, logging, and dataclass patterns.

v1.4.0 original MIT verified 2026-08-12

Coding standards for Python 3.12+ scripts: section layout, import ordering, type hints, logging patterns, dataclass conventions, and AI-agent-friendly design principles. Triggers when generating, modifying, or reviewing .py files, especially for bioinformatics and data-science workflows.

Original work. Created by Yusheng Yang. Not derived from an external project.

What it enforces

Structure

  • 7-section layout

    Imports → Decorators → Constants → Config → Logging → Core → Main. Dependencies flow top-to-bottom; no forward references.

  • 3-tier import grouping

    stdlib → data (pandas/numpy) → third-party, sorted alphabetically. Makes dependency audits instant.

  • All imports at file scope

    No imports buried in function bodies, class definitions, or section headers. Linters catch unused imports reliably.

Modern idioms

  • pathlib.Path everywhere

    Replaces brittle os.path.join with composable, readable, type-safe paths.

  • F-strings only

    No .format() or %. Consistent, fast, readable interpolation.

  • @dataclass(kw_only=True, slots=True, frozen=True)

    Config objects are immutable by default. Hot-reloading is opt-in, not accidental.

  • StrEnum for grouped markers

    Column names, operation modes, categorical statuses. Not for singleton constants.

  • match...case for categorical branches

    Replaces deep if-elif chains with exhaustiveness checking.

Readability

  • Guard clauses at function top

    Edge cases return early; the happy path stays unindented.

  • Single-line docstrings

    Type hints carry the type info. Docstrings state purpose, not signature.

  • @logger.catch on core logic

    Loguru captures tracebacks cleanly. No bare print() calls.

Two advanced patterns

Signal-based classification

Replaces brittle if-elif chains with a declarative signal table + resolution engine. Every rule lives in data (a list of dataclass instances), not control flow. See references/signal-based-classification.md for the full recipe.

Stem-prefix text classification

Classifies every word in semi-structured text (phenotype descriptions, biological annotations) into semantic categories using exact + stem matching. Handles plurals, verb inflections, and hyphenated compounds without listing every form. See references/stem-prefix-classification.md.

When to use

  • Creating any new .py script in the workspace - load this skill first, then open templates/agent_script_template.py as the starting structure.
  • Modifying an existing script - refactor to match when the edit is substantial (layout, imports, logging).
  • Reviewing a PR or diff that includes Python files - use the checklist as review criteria.
  • Generating a single-file script for uv or standalone execution.

When NOT to use

  • Libraries or packages with multiple modules (those follow their own structure).
  • Jupyter notebooks (use the jupyter-live-kernel skill instead).
  • Code snippets in markdown docs.
